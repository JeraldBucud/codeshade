# CodingSensei Brand Assets

CodingSensei uses the tagline **Learn to code by coding.**

Brand assets are grouped by destination:

- `github/` — repository banner and profile image
- `social/` — social/Open Graph preview
- `vscode/` — Marketplace and Activity Bar artwork
- `docs/` — documentation header
- `icons/` — primary application icon
- `logos/` — horizontal and vertical dark/light lockups

## Palette

- Ink Charcoal — `#15171C`
- Copper — `#C96A2B`
- Amber — `#E0A84B`
- Sand — `#F2E7D5`

The approved identity uses the CodingSensei character, conical sensei hat, layered flowing robe, three code lines and warm orange/amber glow. The layered robe represents progressive learning: knowledge builds layer by layer while the learner remains the person writing the code.
